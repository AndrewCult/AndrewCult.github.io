# cultraroandrea.com

My personal site — portfolio and project showcase.
Live at [cultraroandrea.com](https://cultraroandrea.com).

```
index.html          markup and content
assets/style.css    styles
assets/main.js      scroll reveal, active nav item
assets/favicon.svg  logo
```

Hand-written HTML, CSS and JavaScript. No framework, no build step: open
`index.html` and it works. Logo and illustration are hand-written SVG.
Hosted on GitHub Pages from `main`.
